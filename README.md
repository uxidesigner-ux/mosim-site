# 모심 — 화면 미리보기

부모님 병원 동행 서비스 **모심**의 화면 51장을 브라우저에서 볼 수 있는 공개 페이지입니다.

- 전체 캔버스: https://uxidesigner-ux.github.io/mosim-site/
- 개별 화면: `screens/<id>.html` (예: `screens/home.html`)
- 아이콘 시안 비교: `proposals/icon-line.html`

프로토타입 단계의 화면이며, 요금·수수료·취소 규정 등 숫자는 예시값입니다. 사진은 AI로 생성한 이미지(실존 인물 아님, `credits.json`)이고, 컬러 일러스트는 Fluent Emoji(MIT)입니다.
